# Interactive Quiz App

A modern, animated, and responsive quiz game built with **HTML**, **CSS**, and **JavaScript**. This project focuses on clean UI design, smooth transitions, and a user-friendly quiz experience.

---

## 🔗 Live Demo

Visit the demo: [https://nevikai.github.io/interactive-quiz-app](https://nevikai.github.io/interactive-quiz-app)

---

## 🚀 Features

* **Dynamic Questions Rendering** – Loads and displays questions one by one.
* **Smooth Animations** – Transitions, hover effects, progress animations.
* **Responsive Layout** – Works on mobile, tablet, and desktop.
* **Score System** – Calculates and displays results at the end.
* **Progress Bar** – Visual indicator of how many questions remain.
* **Clean UI/UX Design** – Modern, minimal, and easy-to-read interface.
* **Result Screen** – Shows score with a custom message depending on performance.

---

## 🛠️ Technologies Used

* **HTML5** – Page structure
* **CSS3** – Modern styling & animations
* **JavaScript (Vanilla)** – Core logic and interactions

## ▶️ How to Run (Local)

1. Clone the repository:

```bash
git clone https://github.com/Nevikai/interactive-quiz-app.git
```

2. Enter the folder:

```bash
cd interactive-quiz-app
```

3. Open `index.html` in your browser (double-click or `open index.html`).

No build tools or dependencies required.

---

## 🔧 Customization

You can modify:

* **Questions** inside `app.js`
* **Styles/Theme** inside `style.css`
* **Text/Content** inside `index.html`

Everything is designed to be easy to extend.
